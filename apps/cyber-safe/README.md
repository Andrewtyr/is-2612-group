# CYBER SAFE 3.0

Эта копия игры встроена в сайт группы по пути `/cyber-safe`. Монитор доступен
по `/cyber-safe/monitor`. Запуск и хранение описаны в
[`docs/cyber-safe-integration.md`](../../docs/cyber-safe-integration.md).

Для локальной проверки игры выполните `node tests/test_generators.js` и
`node tests/test_server.js` из этой папки.
