# Архитектура

Монорепозиторий: `apps/web` — мобильный интерфейс Next.js, `apps/api` — API NestJS, PostgreSQL — постоянное хранилище. API отвечает за авторизацию, проверку ролей, расписание и посещаемость. Интеграция с академией живёт отдельно в `apps/api/src/integrations/academy`; сбой внешнего сайта не должен останавливать уже сохранённые данные.

Первая группа — ИС-2612. Права всегда проверяются на сервере. Студент получает только собственные данные; староста и заместитель отмечают свою группу; куратор исправляет закрытые отметки. Каждая смена статуса сохраняется в AttendanceHistory и AuditLog.

Официальные источники: [изменения корпуса 3](https://altag.ru/student/schedule/rescheduling-3), [расписание звонков](https://altag.ru/student/schedule/call_schedule), [интерактивное расписание](https://schedule.altag.ru/). Модуль синхронизации получает ИС-2612 из интерактивного расписания, время из таблицы звонков, затем читает PDF изменений на конкретную дату и применяет распознанные строки группы. Он не удаляет сохранённые занятия при сбое или пустом ответе. Ручная правка куратора сохраняет приоритет при последующих синхронизациях.
