# ААГ Интерактив на is2612.ru

Пользователь выбрал отдельный раздел `https://is2612.ru/aag` и новую пустую базу. Код разрабатывается в ветке `codex/aag-interactive`. После проверки ветка сохраняется отдельно, а её изменения включаются в `main` для развёртывания существующим способом.

ААГ работает как самостоятельный контейнер с постоянным томом `/data`. Существующий Next.js перенаправляет запросы `/aag/*` в этот контейнер. Запросы к API ААГ идут через `/aag/api/*`, чтобы не пересекаться с `/api/*` посещаемости. Переход с `/aag` ведёт на `/aag/index.html`, поэтому относительные ссылки архива остаются рабочими. Публичный адрес `https://is2612.ru/aag/` используется в QR-кодах.

У ААГ собственный вход ведущего и администратора. После первого запуска администратор создаётся интерактивной командой в терминале сервера; пароль не передаётся в чат и не хранится в репозитории. Участники могут открывать код занятия без входа. Старые пользователи и материалы не импортируются.

Проверка перед публикацией: тесты ААГ, тесты маршрутов и QR-ссылки, сборка сайта и Docker-образа, затем локальная проверка входа ведущего и участника. На сервере перед запуском сохранить резервную копию основного сайта, создать отдельный постоянный том и проверить `/aag/api/health`. Ветку предоставить пользователю, а включение в основной сайт проводить контролируемо после проверки кода.
