# Порядок реализации

1. Локальная основа: pnpm workspace, Next.js, NestJS, Prisma, PostgreSQL, вход, роли, журнал действий.
2. Расписание: отдельный адаптер академии, расписание звонков, конкретные Lesson, ручная корректировка, история изменений.
3. Посещаемость: отметка группы, ограничения по времени, история, личный кабинет студента.
4. Причины, споры, статистика и интерфейс куратора.
5. Локальная обкатка, исправления, затем родители, PWA и MAX.

Каждый этап проверяется локально командой `pnpm ci:local`. Production сборка и миграции проверяются отдельно через Docker перед выпуском.
