# Сохранение расписания прошедших дат

Обычная синхронизация получает только текущий день и шесть следующих. Если база запущена позже начала семестра, прошлые занятия нужно загрузить отдельно, пока они доступны на сайте академии. После загрузки занятия хранятся в PostgreSQL; последующие синхронизации прошлые даты не удаляют. Резервные копии `scripts/backup.sh` включают эти записи.

Перед импортом сделайте резервную копию базы. Затем из корня репозитория на сервере:

```sh
sudo docker compose -f docker-compose.production.yml exec -T api node apps/api/dist/scripts/backfill-academy-schedule.js --check 2026-09-01 2026-10-05
```

Проверьте количество занятий по дням. Если оно соответствует источнику, добавьте отсутствующие занятия:

```sh
sudo docker compose -f docker-compose.production.yml exec -T api node apps/api/dist/scripts/backfill-academy-schedule.js --apply 2026-09-01 2026-10-05
```

Повторный запуск безопасен: существующие занятия, исправления и отметки посещаемости не меняются. Импорт берёт основной список занятий с сайта академии. Изменения, опубликованные отдельно в PDF, нужно сверять вручную с расписанием за соответствующий день. Для пустого дня команда покажет `0`; при неполной странице источника или неизвестном времени звонка импорт остановится без записи.
