# CYBER SAFE на сайте группы

Игра доступна всем посетителям по адресу `/cyber-safe`. Ссылка находится на
экране входа и в меню пользователя. Монитор организатора доступен по адресу
`/cyber-safe/monitor` и требует отдельный пароль.

Игра работает отдельным контейнером. Next.js проксирует только путь
`/cyber-safe/*` к нему; API расписания, оценок и посещаемости сохраняет путь
`/api/*`. Рейтинг хранится в собственном постоянном Docker-томе. Игровые
сессии остаются в памяти и сбрасываются при перезапуске игрового контейнера.

Перед первым запуском на сервере выполните `sh scripts/setup-cyber-safe.sh`.
Скрипт создаст отдельный файл `.env.cyber-safe` с уникальным паролем монитора
и покажет пароль один раз в вашем терминале. Сохраните его у себя и не
присылайте в чат. Файл исключён из Git. Повторный запуск не меняет пароль.

Затем выполните `docker compose -f docker-compose.production.yml build
cyber-safe web` и `docker compose -f docker-compose.production.yml up -d
cyber-safe web`. Проверьте `/cyber-safe`, `/cyber-safe/monitor`, запись рекорда
и основной `/api/health`.
